# Generated results

This folder contains the small final files used in the presentation:

- `cube_particles.mp4`: the 30 FPS Blender video
- `cube_particles.blend`: the Blender scene
- `preview.png`: the first rendered frame
- `benchmark.csv`: neighborhood-search timings
- `experiments.txt`: Euler, ground and CFL results

The 91 VTK files and 91 PNG files are generated files. They are not stored in
Git because they can be recreated with the commands in the main README.
